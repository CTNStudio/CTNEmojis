# Occultus Emoji

这是星屹工作室的通用 Emoji 库，内嵌于隐藏之年、石头工艺和传说之剑等附加包。

要使用这些 Emoji，你需要将仓库中的`font`目录下所有贴图复制到自己资源包的`font`目录——或者，直接设置隐藏之年为前置附加包。
